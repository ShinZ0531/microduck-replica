# 头部 IMU 诊断组件

遵循 [工程规范](../../docs/engineering/README.md)。

C++ 核心使用实际头颈反馈估计躯干姿态；专用校验 ABI 只计算有界采样窗口的安装解与残差。
两者不访问串口或网络、不控制电机、不写设备文件。
`motionAuthorized` 始终为 0。保留 ABI v1、坐标、时间门限、关节范围及异常语义。

`patches/` 是独立原生运行时的完整增量，不在本仓库假装已经构建了 robotd。
不得把固定躯干的安装验证入口改成对头部 IMU 直接放行。
专用流程由原生主控读取真实数据，保持断力，用户逐步采集后单独确认保存。
核验报告绑定安装变换、模型和头部零位/方向；上手清单提交必须重新核对，不能接受页面伪造的核验结果。
